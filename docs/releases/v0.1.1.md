# CodexDeck 0.1.1

Preview for monitoring Codex usage across isolated accounts. This version corrects fresh macOS CI signing: the isolated signing keychain is temporarily added to the certificate search list, then the previous list is restored on success or failure. A regression test verifies fresh signing and stable identity reuse.

- Five-hour and weekly quotas, reset countdowns, notifications and menu bar summary.
- English by default, with Persian, calendar and theme preferences.
- Encrypted account transfer and explicit one-shot/scheduled prompts.
- Signed macOS original-account switching with system authentication and recovery.
- Windows notification sender identity initialized before sending the first toast. Install using the NSIS installer and keep the Start Menu shortcut.
- Bundled third-party license notices, including font and UI notices.
- Linux GLib string-iteration safety backport; see `vendor/README.md` in the source archive.

## Candidate status

Apple Silicon macOS is locally built and checked. Intel macOS, Windows and Linux need runtime validation. A successful CI build alone does not establish runtime support. Automatic updates are not configured.

Archives/installers whose filenames include `-preview` are experimental. macOS previews have local development signatures and are **not notarized**; Windows previews are **unsigned**. An official macOS archive is produced only after Developer ID signing, Apple notarization, stapling and Gatekeeper validation. Do not describe preview assets as notarized or signed for public Windows distribution.

Each download has a `.sha256` checksum and a `.json` manifest. Verify the checksum before installation. macOS: extract the ZIP and move `CodexDeck.app` to Applications. Windows: run the NSIS installer normally with Start Menu shortcuts enabled. Linux: install the Debian package using the distribution's package manager; a working desktop Secret Service is required for credential storage.

Read the release guide and complete platform installation/account/notification/upgrade checks before publishing the draft. Published assets are never silently replaced by the workflow; corrections require a new version and tag.
