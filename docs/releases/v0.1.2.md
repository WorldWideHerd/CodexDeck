# CodexDeck 0.1.2

This preview adds original-account switching and restoration on Windows for the official OpenAI Codex MSIX app, with a Windows-user-bound DPAPI recovery backup. Save your work and close Codex and its tasks before switching. Select a native Codex CLI executable in Settings. Storage and workspace restrictions are checked before replacing the original login.

- Restore the previous desktop account from Settings, including recovery after an interrupted account change.
- Sync refreshed original credentials only to a matching account card.
- Improve macOS process inspection during shutdown, including exited processes and recycled process IDs.
- Copy the saved local project list, pins and colors into the current macOS Codex account, with system authorization.
- Show platform-appropriate account-switching instructions and keep macOS project-copy actions hidden on Windows.
- Improve Windows notification status and first-toast behavior, and clarify reporting preferences.

## Downloads and validation

Windows x64 NSIS, Linux amd64 Debian, and macOS Apple Silicon/Intel archives are provided with SHA-256 checksums and JSON manifests. CI runs tests and builds on all four platform runners. Windows tests include DPAPI encryption/tamper rejection and isolated file/keyring backup restoration. CI success does not establish interactive account-switching, installation, notification or upgrade compatibility on every platform; runtime checks remain necessary.

These are experimental preview downloads. Windows installers are **unsigned**. macOS archives use local development signatures and are **not notarized**. Automatic updates are not configured.

Verify the matching `.sha256` checksum before installing. On Windows, run the NSIS installer with Start Menu shortcuts enabled. On macOS, extract the ZIP and move `CodexDeck.app` to Applications. On Linux, install the Debian package; credential storage requires a working desktop Secret Service.

See [Windows account-switching validation](https://github.com/WorldWideHerd/CodexDeck/blob/v0.1.2/docs/testing/windows-account-switching.md) for the supported installation and recovery behavior.
