# Contributing

Use the [development guide](docs/development.md) for commands and the [architecture guide](docs/architecture.md) to locate code.

- Describe the problem, change and validation in each pull request.
- Run checks relevant to the change and build the native app after code changes. State which operating system you tested.
- Use synthetic accounts and temporary directories. Keep credentials, login URLs, account archives and signing keys out of commits and reports.
- Preserve `.local-data/`: it contains local signing material and credential broker caches.
- Write documentation, templates, commit messages and code comments in English. Persian text is limited to app localization and its tests/resources.

Report vulnerabilities through [SECURITY.md](SECURITY.md).
